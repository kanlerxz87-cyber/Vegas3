Executive summary

  • Dates. Feb 15, 2027 is Presidents' Day (a federal holiday) — OPM 2027 holidays. A 3-night stay (Feb 15–18) conflicts with the 1–2 week rule; a 7-night stay (Feb 15–22) meets it. You need to choose.
  • Michelin in Las Vegas (2026). Four starred: Joël Robuchon (Two Stars), L'Atelier de Joël Robuchon, Restaurant Guy Savoy, é by José Andrés (One Star each). Three Bib Gourmand. Seventeen Recommended. Thirteen of the 24 are on the Strip (LVCVA).
  • Hotels. Preliminary ranking by Michelin venues on the Strip: The Venetian/Palazzo (4 Recommended), MGM Grand (2 starred), The Cosmopolitan (1 star + 1 Bib). Four hotels have verified room types (2 queens or king); no live 7-night prices were verifiable, so cost columns are blank and flagged.
  • Travel. Red Rock Canyon is ~30 min from the Strip, requires timed entry (Oct 1–May 31), and has no public transit (BLM). The 1-hour bus test has not been run for any pair.
  • Booking timing (official rules only). Starred restaurants usually release tables 30–60 days out. é takes bookings up to three months ahead. Caesars Palace advertises up to 30% off for stays booked 30+ days ahead, terms apply. The cheapest booking date is not yet known.
  • Repo. Only a README existed. Site built as static HTML from one data file; COORDINATION.md created. Irregularities are listed on the Repo review page.
