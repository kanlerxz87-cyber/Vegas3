Suggested order if extending the site

  1. Capture date-specific hotel totals and explicit bathroom confirmation from official hotel sources.
  2. Run RTC itineraries using the shortlisted hotel and actual visit dates/times.
  3. Then build a route-based hotel ranking and couple’s budget roll-up.
  4. Finally add reservation reminders and optional filters/print views.

This order avoids presenting polished scores based on missing prices or inferred travel times. The suggestions table is review-only.
